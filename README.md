# 🌟 My Perfect Day - 

This is a small website I made to create my own magical  page. ✨

It has:


- 🎯 journal 
- 🧚 A fairytale-inspired design
- 🎧 My Spotify playlist

I made this project using HTML and CSS.

I wanted to practice what I have learned in HTML and CSS and also make something creative and personal instead of just making a normal project.

## 🛠️ Built With

- HTML
- CSS

## 💡 What I Learned

While making this project, I learned more about:

- Creating layouts using HTML
- Styling websites with CSS
- Adding images and background images
- Embedding a Spotify playlist
- Making a calendar using tables

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Open `index.html` in your browser.
